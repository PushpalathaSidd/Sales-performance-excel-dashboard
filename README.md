## Project Overview

This project analyzes a retail Superstore dataset to understand sales
performance and the impact of discount levels on profitability. The analysis
was built using Microsoft Excel with Pivot Tables, Pivot Charts, Slicers,
and two fully interactive dashboards.

## Data Cleaning Steps

- Checked for missing values using Go To Special (Ctrl + G)
- Replaced missing postal codes with 0
- Verified consistency of all categorical fields
- Hid unnecessary sheets (People and Returns)

---

## Key Insights

- High discount levels significantly reduce profit margins
- Technology category generates the highest profit margin
- West region shows the highest overall profitability
- Low discount ranges (0 to 20%) maintain healthy profit margins
- Consumer segment contributes the highest share of total sales
